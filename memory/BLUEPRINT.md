# PHILEON BLUEPRINT

## Purpose
This document defines the permanent design philosophy, architecture, and non-negotiable rules governing the PHILEON website. Any future implementation must follow this document before consulting the PRD or CHANGELOG.

## Core Principles
- Editorial before commercial.
- Jewelry is always the hero.
- Luxury through restraint, never excess.
- Museum-quality presentation.
- Quiet motion over loud animation.
- Reusable architecture over one-off solutions.
- Single source of truth for products and pricing.

## Editorial Observation Standard
Every product should feel observed rather than advertised.

Gallery progression:
Object → Observation → Craft → Scale → Motion

Images should emphasize:
- Natural light
- Authentic skin texture
- Premium editorial realism
- Minimal distractions
- Jewelry prominence
- No stock-photo aesthetic

## Architecture Rules
- Shared components first.
- Manifest-driven collections.
- Hero video architecture remains standardized.
- Pricing remains synchronized across frontend and backend.
- Preserve performance and code reuse.

## Do Not Change Without Explicit Approval
- Collection order
- Typography system
- Gold color palette
- Editorial image language
- Museum framing
- Vault architecture
- Shared component architecture
- Pricing architecture
- Product manifest structure
