# PHILEON — PROJECT RULES

## Product Page Editorial Rhythm (forward standard)

Going forward, all PHILEON product pages should follow a consistent editorial rhythm:

1. Hero image or hero video
2. PHILEON title block
3. Editorial sections: **COMPOSITION** / **DETAIL** / **CRAFT** / **FINAL WORD**
4. Gallery
5. Lifestyle or motion section *(if available)*
6. Specifications image *(if available)*
7. Purchase block
8. Market note / trust line

Each piece keeps its own voice:
- **Prise** = dominance
- **La Marva** = structure
- **Annie Rose** = refinement

### Application rules

- This is **layout direction only**, not a rebuild mandate.
- Do **not** rewrite existing pages unless explicitly requested.
- La Marva and Annie Rose currently use the shared `RingProductPage` wrapper. Leave that intact.
- Do not replace existing purchase blocks, do not break the shared component, do not add hero videos unless assets already exist and are explicitly provided by the user.
- New product pages (or pages the user explicitly asks to upgrade) follow this rhythm. Reference page: `/app/frontend/src/pages/CouronnePage.jsx`.
